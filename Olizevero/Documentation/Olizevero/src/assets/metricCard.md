## Universal Metric Card

A one off design for a Metric Card, that can be referenced numerous times throughout any project by simply calling it.

If you wish to call this design, you can do so by importing it at the beginning of a file (as is good practice)

// import MetricCard from 'path/to/MetricCard.js' (in our case ../assets/MetricCard

then to call it where you want it in the program, you can use

<MetricCard 
    "Information here"
/>
